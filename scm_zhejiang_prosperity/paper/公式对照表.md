# 论文公式对照表

## 用于在Word中手动输入或校对公式

---

### 公式1：政策效应定义

**LaTeX代码**：
```
τ_{1t} = Y_{1t}^I - Y_{1t}^N, t ≥ T_0
```

**Word公式编辑器输入**：
```
τ_1t = Y_1t^I - Y_1t^N,  t ≥ T_0
```

**含义**：政策效应等于接受政策干预时的结果减去未接受政策干预时的结果

---

### 公式2：合成控制反事实结果

**LaTeX代码**：
```
Ŷ_{1t}^N = Σ_{j=2}^{J+1} w_j Y_{jt}
```

**Word公式编辑器输入**：
```
Ŷ_1t^N = ∑_(j=2)^(J+1) w_j Y_jt
```

**含义**：合成控制组的反事实结果等于各控制省份结果的加权平均

---

### 公式3：政策效应估计量

**LaTeX代码**：
```
τ̂_{1t} = Y_{1t} - Ŷ_{1t}^N, t ≥ T_0
```

**Word公式编辑器输入**：
```
τ̂_1t = Y_1t - Ŷ_1t^N,  t ≥ T_0
```

**含义**：政策效应的估计值等于实际观测值减去合成控制组的值

---

### 公式4：权重优化问题

**LaTeX代码**：
```
W* = arg min_W (X_1 - X_0 W)' V (X_1 - X_0 W)
```

**Word公式编辑器输入**：
```
W^* = arg⁡ min_W (X_1 - X_0 W)^T V(X_1 - X_0 W)
```

**含义**：最优权重通过最小化预测变量的加权距离来确定

---

## Word公式编辑器快捷键

| 操作 | 快捷键 |
|------|--------|
| 插入公式 | `Alt + =` |
| 上标 | `^` 后输入内容 |
| 下标 | `_` 后输入内容 |
| 求和符号 | `\sum` |
| 希腊字母τ | `\tau` |
| 希腊字母Σ | `\Sigma` |
| 分数 | `\frac` |
| 帽子符号 | `\hat` |

---

## 手动输入步骤

1. 在Word中按 `Alt + =` 插入公式
2. 输入公式内容（使用上述快捷键）
3. 按 `Enter` 确认
